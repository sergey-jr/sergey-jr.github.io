# Sergei Bakaleinik — Portfolio

React + TypeScript + Vite. Russian and English portfolio with case studies and downloadable CV.

## Development

Requires Node.js 22.13+.

```sh
npm install
npm run dev
npm run build
```

## GitHub Pages

In Settings → Pages select **Deploy from a branch**, branch **portfolio-2026**, directory **/docs**.
The checked-in docs directory contains the production build. After editing src or public, run npm run build and commit docs as well. Keep docs/.nojekyll present.

The existing master branch preserves the previous portfolio.
